## Technical Test — Interactive Product Configurator

Build a working replica of the reference configurator provided to you.

## Core Requirements

- React + TypeScript

- Replicate the main configurator experience from the reference

- Allow different product sections to be customized independently

- Support text, image uploads, colors and positioning

- Include 2D editing and 3D preview, with changes synchronized between them

- Store the configuration as structured data

- Architecture should be reusable for other products/configurators

- Responsive and reasonably optimized

- Configurator should be embeddable into another website using an iframe

## Shopify & Pricing

The configurator should be designed to integrate with Shopify.

Demonstrate a basic Shopify integration or mock integration where:

- Customer selections determine the final price

- Different product options/variants can have different prices

- Additional customization costs can be added dynamically

- Pricing is obtained through an API/service rather than hard-coded into the UI

- The final configuration and price can be passed to Shopify when the customer adds the product to cart

## Configuration PDF

Generate a PDF/production summary containing the customer's final configuration, including relevant selections, customization details and preview(s).

The PDF should be structured so it could later be attached to or associated with the Shopify order.

For the test, the pricing/CRM API can be mocked. We are evaluating how you structure the integration so that it can be connected to a real API later.


## Deliverables

- 1. GitHub/GitLab repository

- 2. Working live demo

- 3. Short README explaining the architecture and key technical decisions

## Evaluation

We will evaluate:

- Code quality

- Architecture and scalability

- 2D/3D synchronization

- API integration approach

- Shopify integration approach

- Dynamic pricing logic

- Configuration/data structure

- Performance

- Reusability
